# Practical capstone assessment rubric

This is a **training rubric**, not formal certification.

Score each dimension 0 (missing), 1 (partial), or 2 (usable and supported).

| Dimension | 0 — Missing | 1 — Partial | 2 — Applied |
|---|---|---|---|
| Problem and outcome | No problem | Broad goal | Evidence-based problem and metric |
| Sponsorship | No decision maker | Unclear role | Named accountable decision role |
| Scope and acceptance | Undefined | In/out or criteria only | Boundaries and observable acceptance |
| Delivery plan | No workable plan | Milestones lack dependencies | Owned milestones and dependencies |
| Capacity | Assumed unlimited | Bottleneck mentioned | Constraint and tradeoff documented |
| RAID | No log | Mixed types or missing owners | Risks, issues, assumptions and decisions distinguished |
| Communications | No audience plan | One generic update | Stakeholder-specific messages and cadence |
| Governance | Uncontrolled changes | Approval described vaguely | Impact and accountable approval captured |
| Service transition | Launch equals closure | Partial handoff | Named owner, support and benefits review |
| Reflection | No learning | General reflection | Specific improvement with rationale |

**Interpretation:** 0–9 needs guided practice; 10–15 developing; 16–20 ready for a supervised project exercise. This is an instructional heuristic, not an industry-validated scale.

## Discussion prompts
- Which assumption has the greatest potential impact?
- What evidence would make the sponsor comfortable approving?
- How would you handle a new requirement that adds six weeks?
- When should the team refuse to call the project complete?

The facilitator should provide written feedback against at least two dimensions and allow a revision.
